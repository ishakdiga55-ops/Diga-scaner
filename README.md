
### ⚙️ الأمان

- 🛡️ **Content Security Policy (CSP)** — حماية من XSS
- 🔐 **X-Frame-Options: DENY** — حماية من Clickjacking
- 🚦 **Rate Limiting** — 5 رسائل / دقيقة للمساعد الذكي
- 🔑 **مفاتيح محلية** — لا تُخزّن أي مفاتيح على السيرفر
