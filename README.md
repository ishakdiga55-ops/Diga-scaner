## ✨ الميزات

### 🔌 الاتصال والتشخيص
- ✅ **Web Bluetooth (BLE 4.0)** — اتصال مباشر بأجهزة ELM327 الحديثة
- ✅ **Web Serial (USB)** — دعم الكابلات عبر OTG
- ✅ **وضع تجريبي** — تجربة كل الميزات بدون جهاز
- ✅ **إعادة اتصال تلقائية** — Bluetooth يستعيد الاتصال تلقائياً
- ✅ **كشف البروتوكول** — 10 بروتوكولات OBD2 مختلفة

### 📚 قاعدة بيانات ضخمة
- 📦 **12,458 كود عطل** — دمج ذكي بين 3 مصادر
- 🏭 **أكواد مصنّعين** — تغطية لـ 33 علامة تجارية
- 🔍 **بحث فوري** — بالكود أو الوصف
- 🩺 **بحث بالأعراض** — "اهتزاز المحرك"، "دخان أسود"، "لا تشتغل"...
- 🎯 **تصفية حسب الخطورة** — حرج / خطير / متوسط / منخفض
- 🌳 **تصفّح حسب العائلة** — P0xxx، P2xxx، B0xxx، C0xxx، U0xxx...

### 🧠 التحليل الذكي
- 🎯 **تحليل مبدئي** — قواعد عامة تربط الأكواد بأسبابها
- 💯 **مؤشر صحة السيارة** — من 0 إلى 100
- 📋 **تفاصيل غنية** — أعراض، أسباب، خطوات إصلاح، صعوبة، وقت
- 🔗 **أكواد مرتبطة** — روابط تلقائية

### 📊 قياسات حية
- 📈 **4 عدادات حية** — RPM، السرعة، حرارة المحرك، الوقود
- 📉 **رسم بياني مباشر** — Chart.js
- 🔥 **تحذيرات تلقائية** — حرارة مرتفعة، RPM شاذ، خمول غير مستقر

### 🧪 اختبارات خاصة
- 🔋 **اختبار البطارية والدينامو** — 3 مراحل
- 🌿 **جاهزية الانبعاثات** — Mode 01 PID 01
- 🗑️ **مسح الأعطال** — Mode 04

### 📤 التصدير والمشاركة
- 📄 **تقرير PDF** — يطبع مباشرة
- 💬 **مشاركة واتساب** — ملخص جاهز
- ⭐ **المفضلة** — احفظ الأكواد المهمة
- 🕒 **سجل الفحوصات** — آخر 20 فحص

### 🎨 تجربة المستخدم
- 🌙 **الوضع الليلي/النهاري**
- 🇩🇿 **واجهة عربية RTL** — بخط Cairo
- 📱 **تصميم Mobile-First**
- ⚡ **PWA** — ثبّت على الشاشة
- 💾 **عمل بدون إنترنت**
- 🗜️ **Cache مضغوط** — ضغط 90%
- 🎯 **تمييز مصدر البيانات** — حقيقي / تجريبي

|--------|:-----:|---------|

| **الإجمالي بعد الدمج** | **12,458** | — |

### 🧠 منطق الدمج

1. **OBDex CDN** → بيانات غنية (أعراض، أسباب، خطوات)
2. **ملفات محلية** → أكواد إضافية + إثراء
3. **Wal33D SQLite** → أكواد المصنّعين
4. **دمج ذكي** — لا تكرار، الأفضل يُحتفظ به

## 🚀 البدء السريع

### 🌐 استخدام مباشر

1. افتح: **[ishakdiga55-ops.github.io/Diga-scaner](https://ishakdiga55-ops.github.io/Diga-scaner/)**
2. اضغط **"تجريبي"** للتجربة الفورية
3. أو وصّل ELM327 → **"Bluetooth"** أو **"USB"**

> ⏳ التحميل الأول: 10-15 ثانية. بعدها من الكاش → فوري.

### 📱 التثبيت كتطبيق

| النظام | الطريقة |
|--------|---------|
| **Android Chrome** | ⋮ → "إضافة إلى الشاشة الرئيسية" |
| **iPhone Safari** | مشاركة → "إضافة إلى الشاشة الرئيسية" |
| **Windows/Mac** | أيقونة التثبيت في شريط العنوان |
